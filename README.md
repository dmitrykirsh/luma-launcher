# Luma Launcher

Домашний экран для Google TV и Android TV в оформлении Luma: баннер «Продолжить просмотр» и подборка, ряды приложений, избранное и недавние каналы из [Luma TV](https://github.com/dmitrykirsh/luma-tv), каналы других приложений Google TV (YouTube, Зона, Lampa, NUM, Twitch…), погода и часы. Рядами, баннером и приложениями управляют в настройках на ТВ (шестерёнка справа вверху).

## Возможности
- Баннер сверху собирается из любых источников (продолжить просмотр, тренды, новинки, каналы приложений), порядок и состав настраиваются.
- Ряд «Приложения» показывает только избранные, остальные в «Все приложения». Долгое OK на карточке: добавить, убрать или спрятать из списка.
- Настройки в стиле Luma: ряды и источники сгруппированы по приложениям, порядок меняется «захватом» строки (стрелка вправо к ⇅, OK, стрелки вверх и вниз).
- Значок «нет интернета» рядом с часами, погода (met.no, город по IP).
- Проверка и установка обновлений лаунчера и Luma TV из релизов GitHub (Настройки → Обновления).
- Настройки по умолчанию лежат в `DEFAULTS` в `app/src/main/assets/app.js`, в настройках есть «Сбросить настройки».

## Как это устроено
Оболочка на Kotlin (WebView) и интерфейс на HTML/JS в `app/src/main/assets`, анимации только `transform` и `opacity`.
- Данные Luma читаются из `content://ws.luma.tv.feed/home.json` (нужна Luma TV 1.0.12 или новее). Luma открывается по `luma://open?id=…&play=1` и `luma://tv?id=…`.
- Каналы других приложений читаются из TV Provider и требуют разрешения `READ_TV_LISTINGS`.
- Картинки кэшируются на диск. Картинки YouTube и Google идут через локальный SOCKS5-прокси ByeByeDPI (`127.0.0.1:1080`), если он запущен.
- Кнопку «Домой» на Google TV перехватывает служба доступности `HomeKeyService`.

## Установка
1. Скачайте APK из [релизов](https://github.com/dmitrykirsh/luma-launcher/releases/latest) и установите его с разрешением на каналы:
   ```bash
   adb connect <IP-ТВ>:5555
   adb install -r -g Luma-Launcher-0.2.0.apk
   adb shell pm grant ws.luma.launcher android.permission.READ_TV_LISTINGS
   ```
2. Сделайте лаунчер домашним экраном (в репозитории `tools/set-default.sh`): назначает его домашним и включает службу кнопки «Домой», не трогая остальные службы доступности.
   Откат: `adb shell cmd package set-home-activity com.google.android.apps.tv.launcherx/.home.HomeActivity`.
3. Дальше обновления ставятся прямо из настроек.

## Сборка
```bash
bash tools/deploy.sh                 # debug-сборка, установка на ТВ по adb, запуск
node tools/cdp.mjs "HERO.i"          # отладка страницы на ТВ через DevTools
```
Релизный APK: `gradlew assembleRelease` (подписывается отладочным ключом этого компьютера, поэтому обновления ставятся только поверх сборок, подписанных тем же ключом).
